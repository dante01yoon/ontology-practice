# SDD: 따릉이 요금 계산

근거: `knowledge/source.md` (서울자전거 따릉이 누리집 이용권 안내, 2026-10-28 확인), `knowledge/ontology.md`, `knowledge/PRD.md`.
원본에 없는 내용은 지어내지 않고 "미정의"로 표시했다.

## 1. 개요

이용자, 이용권, 대여시간을 받아 이용권 가격과 추가요금을 계산한다. 이용자가 고를 수 없는 이용권이나 없는 이용권은 거부한다.

## 2. Key Entities

| Entity | 설명 | 주요 속성 | 관계 |
|---|---|---|---|
| 이용자 (Rider) | 이용권을 사서 자전거를 빌리는 사람 | 회원여부: 회원/비회원 | 이용권을 구매한다(1:N), 대여를 한다(1:N) |
| 이용권 (Pass) | 요금을 내고 얻는 이용 자격 | 종류: 일일권/정기권, 기본대여시간: 1·2·3시간, 가격(원) | 기본대여시간을 정한다(1:1) |
| 일일권 (DayPass) | 이용권의 하위 종류 | 기본대여시간: 1·2·3시간 | is-a 이용권 |
| 정기권 (SeasonPass) | 이용권의 하위 종류, 회원 전용 | 기본대여시간: 1·2시간, 이용기간: 7·30·180·365일 | is-a 이용권, 이용기간을 가진다(1:1) |
| 대여 (Rental) | 빌려서 반납하기까지의 한 번 이용 | 대여시간(분), 초과시간(분) | 이용권을 사용한다(N:1), 초과시간이 생길 수 있다(1:0..1) |
| 추가요금 (OverageFee) | 초과시간에 붙는 요금 | 단위시간: 5분, 단위요금: 200원 | 초과시간이 발생시킨다(1:1) |
| 할인 (Discount) | 요금을 깎아 주는 제도 | 미정의 | 추가요금에는 적용되지 않는다 |

## 3. 데이터

### 일일권 가격

| 기본대여시간 | 가격(원) | 비회원 가능 |
|---|---|---|
| 1시간 | 1,000 | 예 |
| 2시간 | 2,000 | 예 |
| 3시간 | 3,000 | 아니오 |

### 정기권 가격 (회원 전용)

| 이용기간 | 1시간권 | 2시간권 |
|---|---|---|
| 7일 | 3,000 | 4,000 |
| 30일 | 5,000 | 7,000 |
| 180일 | 15,000 | 20,000 |
| 365일 | 30,000 | 40,000 |

### 추가요금 상수

| 이름 | 값 |
|---|---|
| 단위시간 | 5분 |
| 단위요금 | 200원 |

## 4. 동작

### 4.1 이용권 가격 구하기

입력: 이용자 회원여부, 이용권 종류, 기본대여시간, (정기권이면) 이용기간

1. 정기권인데 비회원이면 거부한다. (PRD FR-3)
2. 일일권 3시간권인데 비회원이면 거부한다. (PRD FR-4)
3. 가격표에 없는 조합(3시간 정기권, 표에 없는 이용기간 등)이면 거부한다. (PRD FR-5)
4. 가격표에서 가격을 찾아 돌려준다. (PRD FR-1, FR-2)

### 4.2 추가요금 구하기

입력: 기본대여시간(분), 대여시간(분)

1. 초과시간 = max(0, 대여시간 − 기본대여시간)
2. 초과시간이 0이면 0원. (PRD FR-6)
3. 아니면 5분마다 200원. (PRD FR-7)
   - 5분 미만 자투리 처리는 **미정의**. 올림으로 해석하면 ⌈초과시간 / 5⌉ × 200.

### 4.3 총 요금 구하기

총 요금 = 할인 적용한 이용권 가격 + 추가요금 (PRD FR-8, FR-9)

- 할인은 이용권 가격에만 적용한다. 추가요금에는 적용하지 않는다.
- 할인 계산 방식은 **미정의**.

## 5. 거부 조건

| 조건 | 근거 |
|---|---|
| 비회원 + 정기권 | 정기권은 회원 전용 |
| 비회원 + 3시간 일일권 | 비회원은 1·2시간권만 |
| 정기권 + 3시간권 | 원본 표에 없음 |
| 정기권 + 7·30·180·365일 외 이용기간 | 원본 표에 없음 |
| 1·2·3시간 외 기본대여시간 | 원본 표에 없음 |

거부를 예외로 낼지 오류 값으로 돌려줄지는 구현에서 정한다.

## 6. 검증 항목

| 번호 | 입력 | 기대 결과 |
|---|---|---|
| T-1 | 비회원, 일일권 1시간 | 1,000원 |
| T-2 | 회원, 일일권 3시간 | 3,000원 |
| T-3 | 비회원, 일일권 3시간 | 거부 |
| T-4 | 회원, 정기권 30일 2시간 | 7,000원 |
| T-5 | 비회원, 정기권 7일 1시간 | 거부 |
| T-6 | 회원, 정기권 365일 3시간 | 거부 |
| T-7 | 기본 60분, 대여 60분 | 추가요금 0원 (경계 처리 미정의, 원본 문장상 "넘기면"이므로 0원으로 해석) |
| T-8 | 기본 60분, 대여 70분 | 추가요금 400원 |
| T-9 | 기본 60분, 대여 63분 | 미정의 (올림이면 200원, 버림이면 0원) |
| T-10 | 할인 있음, 추가요금 400원 | 추가요금은 그대로 400원 |

## 7. 미정의 사항

- 5분 미만 자투리 처리 (올림/버림)
- 정확히 5분 단위 경계에서의 처리
- 할인의 종류, 대상, 비율
- 정기권 하루 이용 횟수, 한 번 대여의 최대 시간
