# SDD: 따릉이 요금 계산

근거: `knowledge/source.md` (서울자전거 따릉이 누리집 이용권 안내, 2026-10-28 확인), `knowledge/ontology.md`, `knowledge/linked/PRD.md`.
가격표, 추가요금 상수, 규칙은 이 문서에 다시 적지 않는다. `knowledge/ontology.md`의 규칙 번호(R1~R9)와 가격표를 그대로 따른다.
원본에 없는 내용은 지어내지 않고 "미정의"로 표시했다.

## 1. 개요

이용자, 이용권, 대여시간을 받아 이용권 가격과 추가요금을 계산한다. 이용자가 고를 수 없는 이용권이나 없는 이용권은 거부한다.

## 2. Key Entities

개념 정의, 속성 값의 범위, 관계는 ontology.md 1~3절을 따른다. 여기서는 구현 이름만 정한다.

| Entity | 온톨로지 개념 | 관련 규칙 |
|---|---|---|
| Rider | 이용자 (회원/비회원) | R3, R4 |
| Pass | 이용권 | R1, R2 |
| DayPass | 일일권 | R1, R4 |
| SeasonPass | 정기권 | R2, R3, R5 |
| Rental | 대여, 초과시간 | R6 |
| OverageFee | 추가요금 | R6, R7, R8 |
| Discount | 할인 (미정의) | R8, R9 |

## 3. 데이터

- 이용권 가격: ontology.md 2절 "가격표 (이용권.가격)"를 유일한 출처로 쓴다. 코드나 이 문서에 값을 따로 옮겨 적지 않는다.
- 추가요금 단위시간·단위요금: ontology.md 2절 속성표와 R7을 따른다.

## 4. 동작

### 4.1 이용권 가격 구하기

입력: 이용자 회원여부, 이용권 종류, 기본대여시간, (정기권이면) 이용기간

1. R3에 걸리면 거부한다. (PRD FR-3)
2. R4에 걸리면 거부한다. (PRD FR-4)
3. 가격표에 없는 조합(R5)이면 거부한다. (PRD FR-5)
4. 가격표에서 가격을 찾아 돌려준다. (R1, R2 / PRD FR-1, FR-2)

### 4.2 추가요금 구하기

입력: 기본대여시간(분), 대여시간(분)

1. 초과시간은 ontology.md 2절 정의대로 구한다.
2. 추가요금이 붙는지는 R6으로 정한다. (PRD FR-6)
3. 금액은 R7로 계산한다. (PRD FR-7)
   - 자투리 처리는 R7에 적힌 대로 **미정의**.

### 4.3 총 요금 구하기

총 요금은 R9로 구한다. (PRD FR-8, FR-9)

- 할인은 R8에 따라 이용권 가격에만 적용한다.
- 할인 계산 방식은 **미정의**.

## 5. 거부 조건

| 조건 | 근거 |
|---|---|
| 비회원 + 정기권 | R3 |
| 비회원 + 일일권 중 R4가 허용하지 않는 것 | R4 |
| 정기권 + R5에 없는 기본대여시간 | R5 |
| 정기권 + 가격표에 없는 이용기간 | R2 |
| 가격표에 없는 기본대여시간 | R1, R2 |

거부를 예외로 낼지 오류 값으로 돌려줄지는 구현에서 정한다.

## 6. 검증 항목

기대 금액은 적지 않고 규칙과 가격표에서 구한다. 가격이 바뀌어도 이 표는 고칠 필요가 없다.

| 번호 | 입력 | 기대 결과 |
|---|---|---|
| T-1 | 비회원, 일일권 1시간 | R1의 1시간권 가격 |
| T-2 | 회원, 일일권 3시간 | R1의 3시간권 가격 |
| T-3 | 비회원, 일일권 3시간 | 거부 (R4) |
| T-4 | 회원, 정기권 30일 2시간 | 정기권 가격표의 (30일, 2시간권) 값 (R2) |
| T-5 | 비회원, 정기권 7일 1시간 | 거부 (R3) |
| T-6 | 회원, 정기권 365일 3시간 | 거부 (R5) |
| T-7 | 기본 60분, 대여 60분 | 추가요금 0원 (R6의 "넘기면"으로 해석, 경계 처리는 미정의) |
| T-8 | 기본 60분, 대여 70분 | R7로 초과 10분의 추가요금 (자투리 없음) |
| T-9 | 기본 60분, 대여 63분 | 미정의 (R7 자투리 처리에 따름) |
| T-10 | 할인 있음, 추가요금 있음 | 추가요금은 할인 전과 같음 (R8) |

## 7. 미정의 사항

ontology.md 5절을 따른다.
