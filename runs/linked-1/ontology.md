# 따릉이 요금 온톨로지

근거: `knowledge/source.md` (서울자전거 따릉이 누리집 이용권 안내, 2026-10-28 확인).
원본에 없는 내용은 지어내지 않고 "미정의"로 표시했다.

## 1. 개념 (Concepts)

| 개념 | 설명 |
|---|---|
| 이용자 | 이용권을 사서 자전거를 빌리는 사람 |
| 회원 | 이용자의 하위 개념. 모든 이용권을 고를 수 있다 |
| 비회원 | 이용자의 하위 개념. 고를 수 있는 이용권이 제한된다 |
| 이용권 | 요금을 내고 얻는 자전거 이용 자격 |
| 일일권 | 이용권의 하위 개념. 기간 없이 한 번 쓰는 이용권 |
| 정기권 | 이용권의 하위 개념. 정해진 기간 동안 쓰는 이용권, 회원 전용 |
| 기본대여시간 | 이용권이 정하는 한 번 대여의 기본 시간 (1시간·2시간·3시간) |
| 이용기간 | 정기권이 유효한 기간 (7일·30일·180일·365일) |
| 대여 | 이용자가 자전거를 빌려 반납하기까지의 한 번의 이용 |
| 초과시간 | 대여시간 중 기본대여시간을 넘긴 부분 |
| 추가요금 | 초과시간에 붙는 요금 |
| 할인 | 요금을 깎아 주는 제도. 원본에는 "추가요금에는 적용되지 않는다"는 사실만 있고 종류·비율은 미정의 |

### 개념 계층

```
이용자
├── 회원
└── 비회원

이용권
├── 일일권: 1시간권, 2시간권, 3시간권
└── 정기권: {7일, 30일, 180일, 365일} × {1시간권, 2시간권}
```

### 가격표 (이용권.가격)

일일권

| 기본대여시간 | 가격(원) |
|---|---|
| 1시간 | 1,000 |
| 2시간 | 2,000 |
| 3시간 | 3,000 |

정기권

| 이용기간 | 1시간권 | 2시간권 |
|---|---|---|
| 7일 | 3,000 | 4,000 |
| 30일 | 5,000 | 7,000 |
| 180일 | 15,000 | 20,000 |
| 365일 | 30,000 | 40,000 |

정기권 3시간권은 원본에 없다. 존재하지 않는 조합으로 본다.

## 4. 규칙 (Rules)

**R1. 일일권 가격** — 일일권 가격은 기본대여시간에 따라 1시간 1,000원, 2시간 2,000원, 3시간 3,000원이다.

**R2. 정기권 가격** — 정기권 가격은 (이용기간, 기본대여시간) 쌍으로 가격표에서 정해진다.

**R3. 정기권은 회원 전용** — 비회원은 정기권을 고를 수 없다.

**R4. 비회원 일일권 제한** — 비회원은 일일권 중 1시간권 또는 2시간권만 고를 수 있다. (따라서 3시간권은 회원만 고를 수 있다.)

**R5. 정기권 조합 제한** — 정기권은 1시간권과 2시간권만 있다. 3시간 정기권은 없다.

**R6. 추가요금 발생** — 대여시간이 기본대여시간을 넘기면 추가요금이 붙는다. 넘기지 않으면 추가요금은 0원이다.

**R7. 추가요금 계산** — 초과시간 5분마다 200원이다.
- 원본은 5분 미만 자투리(예: 3분 초과)를 올림할지 버림할지 밝히지 않는다. **미정의.**
- 올림으로 해석하면: 추가요금 = ⌈초과시간(분) / 5⌉ × 200
- 경계값(정확히 기본대여시간에 반납, 정확히 5분 초과 등)의 처리도 원본에 명시가 없다.

**R8. 추가요금 할인 불가** — 어떤 할인도 추가요금에는 적용되지 않는다. 할인이 있다면 이용권 가격에만 적용될 수 있다.

**R9. 총 요금** — 한 번의 이용에서 내는 금액 = 이용권 가격(할인 적용 가능) + 추가요금(할인 적용 불가).
- 원본은 총 요금이라는 말을 쓰지 않는다. R1·R2·R6·R8을 합친 해석이다.

## 5. 원본에서 정해지지 않은 것

- 추가요금의 5분 미만 자투리 처리 방식 (올림/버림)
- 기본대여시간과 정확히 같을 때, 5분 단위 경계에서의 처리
- 할인의 종류, 대상, 비율
- 정기권 이용 중 하루 이용 횟수나 한 번 대여의 최대 시간
